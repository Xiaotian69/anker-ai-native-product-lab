# 航旅用电用户访谈提纲

目标：验证问题与行为，不为 Aero 10K 概念寻找赞同。

建议时长：30–40 分钟。参与者应在近 12 个月内有航空或长途交通经历，并经其同意记录匿名笔记。

## 1. 最近一次真实经历

1. 请回忆最近一次超过四小时的出行。你带了哪些需要充电的设备？
2. 移动电源放在哪里？什么时候拿出来，为什么？
3. 当时如何判断它能否携带、剩余多少电、是否正常工作？
4. 有没有发生过线材、空间、温度或规则相关的不便？请描述当时实际做了什么。
5. 如果没有发生问题，也请说明为什么现有方式已经足够。

## 2. 信息与风险判断

1. 请在不搜索的情况下指出这台示例移动电源的容量与 Wh。
2. 哪些状态会让你停止充电或向乘务人员求助？
3. 你通常会查看数字温度吗？哪些提示更容易被注意到？
4. 出发前会在哪里确认承运人的电池要求？

## 3. 无解释概念测试

先展示不带功能说明的概念图，请参与者说出：

- 认为产品解决什么问题；
- 温感环、屏幕、伸缩线和夹扣分别表示什么；
- 哪些信息可信，哪些表述会产生误解；
- 最想删掉和最想保留的功能。

## 4. 任务测试

使用纸模或 3D 模型完成：安装到个人包带、查看状态、连接手机、收回线材、快速取下。记录任务结果、犹豫点和参与者原话，不引导操作。

## 5. 价格与取舍

分别比较通用移动电源与航旅概念的三档价格，不先询问“愿不愿意买”。追问选择依据、放弃条件和可替代方案。

## 记录规范

区分观察、参与者原话、研究员解释和后续假设。没有原始记录的总结不能进入真实证据库。
